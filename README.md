# Social Protection Programme Data Analysis using IBM SPSS

## Project Overview

This project presents a statistical analysis of a social protection programme dataset using **IBM SPSS Statistics**. The analysis focuses on respondent demographics, reliability testing, composite index computation, variable categorization, and Chi-square analysis to support evidence-based decision-making.

---

## Project Objectives

- Analyze respondents' demographic characteristics.
- Assess the reliability of the research instrument.
- Compute composite indices from survey variables.
- Categorize computed indices into analytical groups.
- Examine relationships between variables using Chi-square tests.

---

## Dataset

The dataset contains survey responses collected from beneficiaries of a social protection programme. Statistical analysis was performed using IBM SPSS Statistics.
